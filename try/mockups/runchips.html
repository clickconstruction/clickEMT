Decided here, and yours to decide

Decided here (say if any is wrong)
  • Chips, not drop-downs. Every other field on the sheet is a chip row; the two selects were the only pickers on the phone, and the only ones whose words got cut off.
  • The words and the order are rules.js's. Went to: the shelters, then the hospitals (PERSON_PLACES), each by its name; then With family, Own transport, Not known (LEFT_CHOICES: the word is "Not known", not "Unknown"). The run card is "Bus 3 → High school gym" over the times (transportTimes) and the seats (capacityText); the crew's own division's run first, as openRuns orders them. runsTo would take the same zoneId option, one line.
  • Not on a run is the first card and the default. A row with no run going its way has no run row, as today's hasRuns.
  • A tap keeps the row true. A run tapped sets Went to from its destination; a place tapped that the run does not go to takes the person off the run. Today the Went to box can say one thing while the run goes elsewhere, and the run wins silently at Save.
  • No migration. Save sends transport_id and wherePatch's status and facility_id as today; the desk, the board and the 214 see no difference.

Yours to decide
  • Place first (frames 2 and 3) or run first (frame 4). Recommendation: run first. The crew knows the van at the corner before it knows where the van goes; one tap puts the family on it and the card says the destination. Place first hides the ambulance to the hospital while the gym is lit. Its cost is a longer list under every row, which the fold below contains; if that is still too long, list the runs to the place chosen plus the ones leaving from the crew's own division.
  • Seats on a card, or only the times. Recommendation: show them ("3 of 8"). Whether the family fits is the one thing the crew cannot see from the corner; the drop-down says it today, and the toggle above shows the card without.
  • More than three runs to one place. Wrap them all, or the nearest two and "3 more" (the toggle above). Recommendation: two and More, the crew's division's first, the chosen run always shown; a sheet with gloves should not grow a screen per person.
  • The base's rows in the same release. Recommendation: yes. runSelectHtml is one function on one cell and reads the same rules; the shelter card then says the same thing the phone does. A mouse is fine with a select, so it could wait, but then the two views draw one run two ways.
